◆ sensor_task_get_data()

esp_err_t sensor_task_get_data ( sensor_data_t * data)

Obtener datos de sensores de forma thread-safe.

Lee los datos de sensores desde la estructura compartida protegida por mutex. Bloquea hasta 100ms esperando el mutex.

Parámetros
[out]dataPuntero a estructura donde se copiarán los datos
Devuelve
ESP_OK si los datos fueron leídos correctamente
ESP_ERR_INVALID_ARG si data es NULL
ESP_ERR_TIMEOUT si no se pudo adquirir el mutex en 100ms
Atención
Siempre verificar el return value antes de usar los datos
Nota
Esta función es thread-safe y puede llamarse desde cualquier tarea

Obtener datos de sensores de forma thread-safe.

Implementa lectura segura desde cualquier contexto (tarea o ISR si se usa FromISR).

  • Adquiere mutex con timeout de 100ms
  • Copia estructura completa (atomic memcpy)
  • Libera mutex inmediatamente

Uso desde múltiples tareas: Esta función es completamente thread-safe. Puede ser llamada simultáneamente desde HTTP server, display task, keypad task, etc. El mutex garantiza que nunca se lean datos parcialmente actualizados.

Ejemplo de uso:

sensor_data_t data;
if (sensor_task_get_data(&data) == ESP_OK) {
if (data.temperature_valid) {
printf("Temp: %.1f C\n", data.temperature_celsius);
}
if (data.time_valid) {
printf("Hora: %02d:%02d\n", data.time_info.tm_hour, data.time_info.tm_min);
}
}

◆ sensor_task_init()

esp_err_t sensor_task_init ( adc_oneshot_unit_handle_t handle)

Inicializar tarea de sensores.

Crea una tarea FreeRTOS que lee sensores cada 2 segundos y actualiza los datos compartidos de forma thread-safe usando un mutex.

Parámetros
adc_handleHandle del ADC configurado para el sensor NTC
Devuelve
ESP_OK si la inicialización fue exitosa
ESP_ERR_NO_MEM si no hay memoria para crear el mutex o la tarea
ESP_FAIL si falla la creación de la tarea
Nota
Esta función debe llamarse después de inicializar el ADC y antes de cualquier llamada a sensor_task_get_data()

Inicializar tarea de sensores.

Secuencia de inicialización:

  1. Guarda handle del ADC en variable estática
  2. Crea mutex para protección de datos compartidos
  3. Crea tarea sensor_update_task con parámetros predefinidos

Recursos creados:

  • 1 Mutex binario (sensor_mutex)
  • 1 Tarea RTOS (3072 bytes de stack)
Parámetros
[in]handleHandle del ADC previamente configurado con ntc_driver
Devuelve
esp_err_t
Valores devueltos
ESP_OKInicialización exitosa
ESP_ERR_NO_MEMNo hay memoria para crear mutex
ESP_FAILError al crear tarea RTOS
Atención
Llamar solo una vez durante inicialización del sistema
El handle del ADC debe estar inicializado con inicializar_ntc()
