◆ COEFICIENTE_BETA_NTC

#define COEFICIENTE_BETA_NTC   3950.0f

Coeficiente Beta del NTC (3950K).

El coeficiente Beta caracteriza la variación de resistencia con temperatura. Se obtiene de la hoja de datos del fabricante. Un Beta típico para NTC 10K es 3950K ± 1%.

La ecuación relacionada es:

R(T) = R0 * exp(B * (1/T - 1/T0))
