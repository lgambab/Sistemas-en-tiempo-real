Descripción detallada

Implementación del driver para sensor NTC con conversión Steinhart-Hart.

Autor
Jair Hernan Telpis Cuaran, Luis Fernando Gamba Bedoya
Fecha
2025

Implementa la lectura del termistor NTC mediante ADC y conversión a temperatura usando la ecuación simplificada de Steinhart-Hart con coeficiente Beta.

Configuración de hardware:

  • NTC 10KΩ @ 25°C conectado a GPIO 34
  • Divisor de voltaje: R_div = 10KΩ
  • VCC = 3.3V
  • ADC: 12 bits, atenuación 12dB

Circuito equivalente:

VCC (3.3V)
|
[R_div = 10KΩ]
|
+-----> GPIO 34 (ADC1_CH6)
|
[R_ntc = f(T)]
|
GND

◆ inicializar_ntc()

void inicializar_ntc ( adc_oneshot_unit_handle_t manejador_adc)

Configura el canal ADC para el termistor NTC.

Inicializa el canal ADC para el sensor NTC.

Establece la configuración del canal ADC con:

  • Atenuación 12dB: rango completo 0-3.3V
  • Resolución por defecto: 12 bits (0-4095)

La atenuación de 12dB es necesaria porque el divisor de voltaje produce voltajes en todo el rango 0-3.3V dependiendo de la temperatura.

◆ leer_temperatura_celsius()

float leer_temperatura_celsius ( adc_oneshot_unit_handle_t manejador_adc)

Realiza lectura ADC y convierte a temperatura usando Steinhart-Hart.

Lee la temperatura actual del sensor NTC en grados Celsius.

Algoritmo de conversión:

  1. Lectura ADC: Obtiene valor digital (0-4095)
  2. Conversión a voltaje: V = ADC_raw * (3300mV / 4095)
  3. Cálculo de resistencia NTC:
    R_ntc = R_div * V / (V_ref - V)
  4. Ecuación Steinhart-Hart simplificada:
    1/T = 1/T0 + (1/B) * ln(R_ntc / R0)
  5. Conversión K → °C: T_celsius = T_kelvin - 273.15

Detección de errores:

  • V ≥ V_ref: Circuito abierto (NTC desconectado)
  • R_ntc ≤ 0: Cortocircuito o error matemático
Parámetros
[in]manejador_adcHandle del ADC configurado
Devuelve
Temperatura en °C o -999.0f en caso de error
