Descripción detallada

Control automático del ventilador con múltiples modos de operación.

Autor
Jair Hernan Telpis Cuaran, Luis Fernando Gamba Bedoya
Fecha
2025
Versión
1.0.0

Implementa la lógica de control del ventilador con tres modos:

  • MANUAL: Control directo por slider de la interfaz web
  • AUTO: Control automático basado en temperatura del sensor NTC
  • REGISTERS: Control programado mediante registros horarios

◆ fan_control_init()

void fan_control_init ( void )

Inicializar sistema de control del ventilador.

Inicializar sistema de control del ventilador.

Secuencia de inicialización:

  1. Inicializa hardware PWM (fan_init())
  2. Configura modo MANUAL por defecto
  3. Velocidades a 0%
  4. Apaga ventilador

Estado inicial:

  • Modo: FAN_MODE_MANUAL
  • Velocidad manual: 0%
  • Velocidad actual: 0%
  • Registro activo: false
  • PWM: apagado
Atención
Llamar antes de usar cualquier otra función de fan_control
Nota
Thread-safe: solo llamar una vez durante inicialización

Llamado cada 10 segundos por registers_scheduler_task. Solo tiene efecto si el modo actual es FAN_MODE_REGISTERS.

◆ fan_control_set_mode()

void fan_control_set_mode ( fan_mode_t mode)

Establecer modo de operación del ventilador.

Parámetros
modeNuevo modo (MANUAL, AUTO o REGISTERS)

Establecer modo de operación del ventilador.

Actualiza el modo y aplica lógica correspondiente inmediatamente:

MANUAL:

  • Aplica velocidad del slider directamente
  • No requiere sensores

AUTO:

  • Lee temperatura NTC
  • Calcula velocidad con compute_auto_speed()
  • Si ADC NULL o error NTC: apaga ventilador
  • PIR deshabilitado en esta versión (comentado)

REGISTERS:

  • Si hay registro activo: aplica velocidad del slider
  • Si no hay registro: apaga ventilador
Parámetros
[in]modeNuevo modo (FAN_MODE_MANUAL/AUTO/REGISTERS)
Atención
No es thread-safe: llamar solo desde HTTP server task
Nota
Cambio de modo aplica velocidad inmediatamente (no espera a fan_task)

◆ fan_control_update()

void fan_control_update ( void )

Actualizar control (llamado cada 1s por fan_task).

En modo AUTO ajusta velocidad según temperatura NTC

Actualizar control (llamado cada 1s por fan_task).

Llamado cada 1 segundo por fan_task. Solo tiene efecto si el modo actual es FAN_MODE_AUTO.

Algoritmo de actualización:

  1. Verifica que el modo sea AUTO (si no, retorna)
  2. Verifica que el ADC esté inicializado
  3. Lee temperatura del NTC
  4. Valida lectura (> -100°C)
  5. Calcula velocidad con compute_auto_speed()
  6. Actualiza PWM con fan_set_speed_percent()

Manejo de errores:

  • Si ADC handle es NULL: apaga ventilador
  • Si temperatura < -100°C: apaga ventilador (error NTC)
  • PIR deshabilitado: no verifica movimiento (comentado)
Nota
Llamado desde fan_task cada 1 segundo
Solo procesa en modo AUTO (retorna inmediatamente en otros modos)
Atención
No es thread-safe con cambios de modo simultáneos
