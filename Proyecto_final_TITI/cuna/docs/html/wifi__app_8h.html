Descripción detallada

Gestión completa de WiFi AP/STA con reconexión automática y persistencia.

Autor
Jair Hernan Telpis Cuaran, Luis Fernando Gamba Bedoya
Fecha
2025
Versión
1.0.0

Módulo que gestiona la configuración dual WiFi (Access Point + Station) del ESP32:

  • Access Point (AP): Crea red WiFi para configuración inicial
  • Station (STA): Se conecta a redes WiFi existentes
  • Reconexión Automática: Reintenta conexión hasta MAX_CONNECTION_RETRIES veces
  • Persistencia NVS: Guarda credenciales WiFi para reconexión tras reinicio
  • Sincronización SNTP: Obtiene hora de servidores NTP cuando se conecta
  • Cola de Mensajes RTOS: Comunicación thread-safe con el servidor HTTP

El sistema inicia en modo AP+STA, permitiendo configuración web mientras mantiene el AP activo. Las credenciales se guardan en NVS y se cargan automáticamente al reiniciar.

◆ task_compare_hour_to_execute_action()

void task_compare_hour_to_execute_action ( void * pvParameters)

Tarea que compara hora actual con registros programados.

Parámetros
pvParametersParámetros de la tarea (sin usar)

Ejecuta cada minuto, activa ventilador si hay coincidencia horaria

Tarea que compara hora actual con registros programados.

Espera a que SNTP sincronice, luego cada 60s compara hora actual con registros programados. Si coincide, ejecuta acción (ventilador).

Proceso:

  1. Espera a get_state_time_was_synchronized() == true
  2. Cada 60s obtiene hora con time() y localtime_r()
  3. Itera registros y compara con compare_hour_day_structs()
  4. Si coincide, ejecuta acción del registro
Parámetros
[in]pvParametersParámetro de tarea (no usado)
Nota
Tarea infinita, stack 4096 bytes, prioridad 5
