Descripción detallada

Evento enviado por la cola cuando el PIR detecta cambio.

Esta estructura se envía a través de la cola cuando el sensor PIR cambia de estado (flanco de subida o bajada).

Uso:

QueueHandle_t pir_queue = xQueueCreate(10, sizeof(pir_event_t));
pir_init(GPIO_NUM_35, pir_queue);
pir_event_t evt;
if (xQueueReceive(pir_queue, &evt, portMAX_DELAY)) {
if (evt.motion) {
printf("Movimiento detectado!\n");
} else {
printf("Fin de movimiento\n");
}
}
