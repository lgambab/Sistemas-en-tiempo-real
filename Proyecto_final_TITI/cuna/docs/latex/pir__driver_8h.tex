\doxysubsection{Descripción detallada}
Driver para sensor PIR (Passive Infrared) de detección de movimiento. 

\begin{DoxyAuthor}{Autor}

Este módulo proporciona driver para sensores PIR HC-\/\+SR501 o compatibles. El sensor detecta movimiento mediante cambios en la radiación infrarroja.

{\bfseries{Hardware\+:}}
\begin{DoxyItemize}
\item Sensor PIR HC-\/\+SR501 (o compatible)
\item Pin OUT conectado a GPIO 35 (configurable)
\item VCC\+: 5V, GND\+: GND
\item Salida digital\+: HIGH cuando detecta movimiento
\end{DoxyItemize}

{\bfseries{Modos de operación\+:}}
\begin{DoxyEnumerate}
\item {\bfseries{Polling\+:}} Llamar \doxylink{pir__driver_8h_a81ffd3f243f99fd46341ee96793e6310}{pir\+\_\+is\+\_\+motion\+\_\+active()} periódicamente
\item {\bfseries{Interrupt\+:}} Pasar una cola a \doxylink{pir__driver_8h_a27ed60104c030cfcf7d4d4cb5d79529d}{pir\+\_\+init()} para recibir eventos
\end{DoxyEnumerate}

{\bfseries{Configuración del sensor HC-\/\+SR501\+:}}
\begin{DoxyItemize}
\item Delay time\+: Ajusta cuánto tiempo permanece HIGH después de detección
\item Sensitivity\+: Ajusta el rango de detección (3-\/7 metros típico)
\item Trigger mode\+: Repeatable (H) o Non-\/repeatable (L)
\end{DoxyItemize}

\begin{DoxyNote}{Nota}
Este driver soporta tanto ISR como polling 
\end{DoxyNote}
