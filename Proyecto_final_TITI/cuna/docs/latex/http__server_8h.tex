\doxysubsection{Descripción detallada}
Servidor HTTP con endpoints REST para control del sistema. 

\begin{DoxyAuthor}{Autor}
Jair Hernan Telpis Cuaran, Luis Fernando Gamba Bedoya 
\end{DoxyAuthor}
\begin{DoxyDate}{Fecha}
2025 
\end{DoxyDate}
\begin{DoxyVersion}{Versión}
1.\+0.\+0
\end{DoxyVersion}
Servidor HTTP embebido que proporciona\+:
\begin{DoxyItemize}
\item {\bfseries{Interfaz Web Completa}}\+: HTML/\+CSS/\+JS para control del sistema
\item {\bfseries{Endpoints REST}}\+: Control de ventilador, registros, sensores
\item {\bfseries{OTA Updates}}\+: Actualización de firmware vía HTTP
\item {\bfseries{Monitoreo de Estado}}\+: Cola de mensajes para eventos Wi\+Fi y sistema
\item {\bfseries{Archivos Embebidos}}\+: \doxylink{index_8html}{index.\+html}, \doxylink{app_8js}{app.\+js}, app.\+css, j\+Query, favicon
\end{DoxyItemize}

{\bfseries{Principales Endpoints\+:}}
\begin{DoxyItemize}
\item GET / → Página web principal
\item GET /dht\+Sensor.json → Leer temperatura y PIR
\item POST /fan\+Settings.json → Configurar ventilador
\item POST /regchange.json → Modificar registro programado
\item GET /api/register → API de registros (ver \doxylink{registers_8h}{registers.\+h})
\item POST /\+OTAupdate → Actualización OTA de firmware
\end{DoxyItemize}

El servidor se inicializa automáticamente cuando Wi\+Fi se conecta y mantiene una tarea monitor que procesa mensajes de estado del sistema.
