\doxysubsection{Descripción detallada}
Servidor HTTP con REST API para control del sistema. 

\begin{DoxyAuthor}{Autor}
Jair Hernan Telpis Cuaran, Luis Fernando Gamba Bedoya 
\end{DoxyAuthor}
\begin{DoxyDate}{Fecha}
2025
\end{DoxyDate}
Implementa servidor HTTP completo con endpoints REST para\+:
\begin{DoxyItemize}
\item Control de ventilador (manual/auto/registros)
\item Lectura de sensores (temperatura, PIR)
\item Gestión de registros programados (CRUD)
\item Configuración Wi\+Fi
\item Actualización OTA de firmware
\item Servicio de archivos estáticos (HTML, CSS, JS)
\end{DoxyItemize}

{\bfseries{Endpoints principales\+:}}
\begin{DoxyItemize}
\item GET /dht\+Sensor.json → Sensores (temp, PIR)
\item POST /fan\+Control.json → Control ventilador
\item GET /api/registers → Lista todos los registros
\item POST /api/register → Crear/actualizar registro
\item DELETE /api/register/\{id\} → Eliminar registro
\item POST /wifi\+Connect.json → Conectar Wi\+Fi
\item POST /\+OTAupdate → Actualización firmware
\end{DoxyItemize}
