Obtener datos de sensores de forma thread-\/safe.

Implementa lectura segura desde cualquier contexto (tarea o ISR si se usa From\+ISR).
\begin{DoxyItemize}
\item Adquiere mutex con timeout de 100ms
\item Copia estructura completa (atomic memcpy)
\item Libera mutex inmediatamente
\end{DoxyItemize}

{\bfseries{Uso desde múltiples tareas\+:}} Esta función es completamente thread-\/safe. Puede ser llamada simultáneamente desde HTTP server, display task, keypad task, etc. El mutex garantiza que nunca se lean datos parcialmente actualizados.
