Driver para sensor de temperatura NTC (Negative Temperature Coefficient). 

\begin{DoxyAuthor}{Autor}
Jair Hernan Telpis Cuaran, Luis Fernando Gamba Bedoya

Este módulo implementa el driver para leer temperatura mediante un termistor NTC 10KΩ conectado en configuración divisor de voltaje con el ADC del ESP32.

{\bfseries{Hardware\+:}}
\begin{DoxyItemize}
\item Termistor NTC 10KΩ @ 25°C (Beta = 3950K)
\item Conectado a GPIO 34 (ADC1 Canal 6)
\item Resistencia divisor\+: 10KΩ
\item Rango de medición\+: -\/40°C a 125°C
\end{DoxyItemize}

{\bfseries{Ecuación de conversión\+:}} Se utiliza la ecuación simplificada de Steinhart-\/\+Hart\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{1/T\ =\ 1/T0\ +\ (1/B)\ *\ ln(R/R0)}

\end{DoxyCode}
 Donde\+:
\begin{DoxyItemize}
\item T = Temperatura absoluta en Kelvin
\item T0 = Temperatura nominal (298.\+15K = 25°C)
\item B = Coeficiente Beta (3950K)
\item R = Resistencia actual del NTC
\item R0 = Resistencia nominal (10kΩ)
\end{DoxyItemize}

{\bfseries{Manejo de errores\+:}}
\begin{DoxyItemize}
\item Retorna -\/999.\+0f en caso de circuito abierto o cortocircuito
\item Verifica voltajes fuera de rango (\texorpdfstring{$>$}{>}3.\+3V o \texorpdfstring{$<$}{<}0V)
\item Valida resistencias negativas o nulas 
\end{DoxyItemize}

Inicializa el canal ADC para el sensor NTC. 

Configura el canal ADC\+\_\+\+CHANNEL\+\_\+6 (GPIO 34) con las siguientes características\+:

\item Modo\+: Oneshot (lectura bajo demanda)

Lee la temperatura actual del sensor NTC en grados Celsius. 

Proceso de lectura y conversión\+:
\begin{DoxyEnumerate}
\item Lee valor ADC raw (0-\/4095)
\item Convierte a voltaje\+: V = (ADC\+\_\+raw \texorpdfstring{$\ast$}{*} 3300mV) / 4095
\item Calcula resistencia NTC\+: R\+\_\+ntc = R\+\_\+div \texorpdfstring{$\ast$}{*} V / (V\+\_\+ref -\/ V)
\item Aplica Steinhart-\/\+Hart\+: 1/T = 1/\+T0 + (1/B)\texorpdfstring{$\ast$}{*}ln(R/\+R0)
\item Convierte Kelvin a Celsius\+: T\+\_\+c = T\+\_\+k -\/ 273.\+15
\end{DoxyEnumerate}

{\bfseries{Ecuación del divisor de voltaje\+:}} 
\begin{DoxyCode}{0}
\DoxyCodeLine{V\_out\ =\ V\_in\ *\ (R\_ntc\ /\ (R\_div\ +\ R\_ntc))}

\end{DoxyCode}


{\bfseries{Precisión\+:}}
\begin{DoxyItemize}
\item Resolución ADC\+: \texorpdfstring{$\sim$}{\string~}0.8mV (3300mV / 4095)
\item Error típico\+: ±1°C en rango 0-\/50°C
\item Error aumenta fuera del rango nominal
\end{DoxyItemize}
