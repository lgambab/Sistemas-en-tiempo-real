\doxysubsection{Descripción detallada}
Implementación de tarea RTOS para lectura thread-\/safe de sensores. 

\begin{DoxyAuthor}{Autor}
Jair Hernan Telpis Cuaran, Luis Fernando Gamba Bedoya 
\end{DoxyAuthor}
\begin{DoxyDate}{Fecha}
2025
\end{DoxyDate}
Este módulo implementa una arquitectura thread-\/safe para acceso a sensores en Free\+RTOS. Soluciona el problema de compartir el handle del ADC entre múltiples tareas mediante\+:
\begin{DoxyItemize}
\item Tarea dedicada que lee sensores cada 2 segundos
\item Mutex para proteger estructura de datos compartida
\item API de acceso segura para otras tareas (HTTP server, display, etc.)
\end{DoxyItemize}

Obtener datos de sensores de forma thread-\/safe.

Implementa lectura segura desde cualquier contexto (tarea o ISR si se usa From\+ISR).
\begin{DoxyItemize}
\item Adquiere mutex con timeout de 100ms
\item Copia estructura completa (atomic memcpy)
\item Libera mutex inmediatamente
\end{DoxyItemize}

{\bfseries{Uso desde múltiples tareas\+:}} Esta función es completamente thread-\/safe. Puede ser llamada simultáneamente desde HTTP server, display task, keypad task, etc. El mutex garantiza que nunca se lean datos parcialmente actualizados.

Tarea RTOS que actualiza sensores periódicamente. 

{\bfseries{Ciclo de ejecución\+:}}
\begin{DoxyEnumerate}
\item Lee temperatura del NTC (si adc\+\_\+handle válido)
\item Obtiene hora actual del sistema (time() + localtime\+\_\+r())
\item Valida datos (temperatura \texorpdfstring{$>$}{>} -\/100°C, año \texorpdfstring{$>$}{>} 2000)
\item Actualiza shared\+\_\+sensor\+\_\+data con protección de mutex
\item Espera 2 segundos (v\+Task\+Delay)
\end{DoxyEnumerate}

{\bfseries{Parámetros de la tarea\+:}}
\begin{DoxyItemize}
\item Nombre\+: "{}sensor\+\_\+task"{}
\item Stack\+: 3072 bytes
\item Prioridad\+: config\+MAX\+\_\+\+PRIORITIES -\/ 3 (prioridad media)
\item Periodo\+: 2000ms
\end{DoxyItemize}

{\bfseries{Manejo de errores\+:}}
\begin{DoxyItemize}
\item Si ADC handle es NULL\+: temperature\+\_\+valid = false
\item Si temperatura \texorpdfstring{$<$}{<} -\/100°C\+: temperatura inválida (error NTC)
\item Si tm\+\_\+year \texorpdfstring{$<$}{<} 100\+: hora aún no sincronizada con SNTP
\item Si mutex no disponible en 100ms\+: skip update (sin crash)
\end{DoxyItemize}
