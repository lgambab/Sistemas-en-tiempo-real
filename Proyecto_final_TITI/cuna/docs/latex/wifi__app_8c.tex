\doxysubsection{Descripción detallada}
Aplicación Wi\+Fi con soporte AP/\+STA dual, reconexión automática y SNTP. 

\begin{DoxyAuthor}{Autor}
Jair Hernan Telpis Cuaran, Luis Fernando Gamba Bedoya 
\end{DoxyAuthor}
\begin{DoxyDate}{Fecha}
2025
\end{DoxyDate}
Este módulo implementa la gestión completa de Wi\+Fi para el ESP32\+:

{\bfseries{Modos de operación\+:}}
\begin{DoxyEnumerate}
\item {\bfseries{Access Point (AP)\+:}} Para configuración inicial
\begin{DoxyItemize}
\item SSID\+: Configurable
\item Usuario puede conectarse para configurar credenciales
\end{DoxyItemize}
\item {\bfseries{Station (STA)\+:}} Conexión a red Wi\+Fi existente
\begin{DoxyItemize}
\item Credenciales almacenadas en NVS
\item Reconexión automática tras desconexión
\item Máximo de reintentos configurable
\end{DoxyItemize}
\item {\bfseries{Dual AP+\+STA\+:}} Permite configuración mientras mantiene conexión
\end{DoxyEnumerate}

{\bfseries{Características\+:}}
\begin{DoxyItemize}
\item Sincronización de tiempo mediante SNTP (pool.\+ntp.\+org)
\item Persistencia de credenciales en NVS flash
\item Event handlers para Wi\+Fi (connect, disconnect, got IP)
\item Cola de mensajes para comunicación entre tareas
\item LED RGB indicador de estado
\item Notificación al HTTP server de cambios de estado
\end{DoxyItemize}
