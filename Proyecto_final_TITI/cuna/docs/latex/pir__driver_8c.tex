\begin{DoxyDate}{Fecha}

Implementa driver para sensor PIR HC-\/\+SR501 con dos modos de operación\+:

{\bfseries{Modo ISR (con cola)\+:}}
\begin{DoxyItemize}
\item Detecta flancos de subida y bajada automáticamente
\item Envía eventos a cola Free\+RTOS
\item Ideal para respuesta inmediata
\end{DoxyItemize}

{\bfseries{Modo Polling (sin cola)\+:}}
\begin{DoxyItemize}
\item Lee estado bajo demanda con \doxylink{pir__driver_8c_a81ffd3f243f99fd46341ee96793e6310}{pir\+\_\+is\+\_\+motion\+\_\+active()}
\item Más simple, usado por sensor\+\_\+task
\item Menor consumo de CPU
\end{DoxyItemize}

{\bfseries{Variables estáticas\+:}}
\begin{DoxyItemize}
\item s\+\_\+pir\+\_\+gpio\+: Pin configurado para el sensor
\item s\+\_\+pir\+\_\+evt\+\_\+queue\+: Cola para eventos (NULL en modo polling)
\end{DoxyItemize}

Inicializa el sensor PIR configurando GPIO e ISR. 

Inicializa el sensor PIR con ISR o polling.

Secuencia de inicialización\+:
\begin{DoxyEnumerate}
\item Guarda parámetros en variables estáticas
\item Configura GPIO como entrada sin pull-\/up/down
\item Habilita interrupción en ambos flancos (ANYEDGE)
\item Instala servicio ISR global (si no existe)
\item Registra handler específico para este pin
\end{DoxyEnumerate}

{\bfseries{Configuración GPIO\+:}}
\begin{DoxyItemize}
\item Modo INPUT\+: Lee nivel lógico del sensor
\item Sin pull-\/up/down\+: Sensor tiene electrónica interna
\item ANYEDGE\+: Detecta inicio (LOW→\+HIGH) y fin (HIGH→\+LOW)
\end{DoxyItemize}

{\bfseries{Alternativa solo subida\+:}} Cambiar a GPIO\+\_\+\+INTR\+\_\+\+POSEDGE para solo notificar inicio de movimiento.

ISR (Interrupt Service Routine) del sensor PIR. 

Se ejecuta automáticamente cuando el pin del PIR cambia de estado.

{\bfseries{Proceso\+:}}
\begin{DoxyEnumerate}
\item Verifica que la cola esté configurada
\item Lee nivel actual del GPIO
\item Crea evento con estado del sensor
\item Envía a cola desde ISR (x\+Queue\+Send\+From\+ISR)
\item Yield si una tarea de mayor prioridad está esperando
\end{DoxyEnumerate}

{\bfseries{Características ISR\+:}}
\begin{DoxyItemize}
\item Atributo IRAM\+\_\+\+ATTR\+: Código en RAM para ejecución rápida
\item Context\+: Interrupt context (no puede usar funciones bloqueantes)
\item Tiempo\+: \texorpdfstring{$<$}{<}10μs típico
\end{DoxyItemize}
