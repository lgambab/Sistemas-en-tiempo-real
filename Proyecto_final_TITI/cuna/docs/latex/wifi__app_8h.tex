\doxysubsection{Descripción detallada}
Gestión completa de Wi\+Fi AP/\+STA con reconexión automática y persistencia. 

\begin{DoxyAuthor}{Autor}
Jair Hernan Telpis Cuaran, Luis Fernando Gamba Bedoya 
\end{DoxyAuthor}
\begin{DoxyDate}{Fecha}
2025 
\end{DoxyDate}
\begin{DoxyVersion}{Versión}
1.\+0.\+0
\end{DoxyVersion}
Módulo que gestiona la configuración dual Wi\+Fi (Access Point + Station) del ESP32\+:
\begin{DoxyItemize}
\item {\bfseries{Access Point (AP)}}\+: Crea red Wi\+Fi para configuración inicial
\item {\bfseries{Station (STA)}}\+: Se conecta a redes Wi\+Fi existentes
\item {\bfseries{Reconexión Automática}}\+: Reintenta conexión hasta MAX\+\_\+\+CONNECTION\+\_\+\+RETRIES veces
\item {\bfseries{Persistencia NVS}}\+: Guarda credenciales Wi\+Fi para reconexión tras reinicio
\item {\bfseries{Sincronización SNTP}}\+: Obtiene hora de servidores NTP cuando se conecta
\item {\bfseries{Cola de Mensajes RTOS}}\+: Comunicación thread-\/safe con el servidor HTTP
\end{DoxyItemize}

El sistema inicia en modo AP+\+STA, permitiendo configuración web mientras mantiene el AP activo. Las credenciales se guardan en NVS y se cargan automáticamente al reiniciar.
