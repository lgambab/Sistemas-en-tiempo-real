\doxysubsection{Descripción detallada}
API REST para gestión de registros programados con persistencia NVS. 

\begin{DoxyAuthor}{Autor}
Jair Hernan Telpis Cuaran, Luis Fernando Gamba Bedoya 
\end{DoxyAuthor}
\begin{DoxyDate}{Fecha}
2025 
\end{DoxyDate}
\begin{DoxyVersion}{Versión}
1.\+0.\+0
\end{DoxyVersion}
Sistema completo de registros programados que permite\+:
\begin{DoxyItemize}
\item Crear, leer y eliminar registros mediante endpoints HTTP REST
\item Almacenar registros en NVS (Non-\/\+Volatile Storage) con formato JSON
\item Comparar hora actual con registros para activar automáticamente el ventilador
\item Sincronización mediante SNTP para precisión horaria
\end{DoxyItemize}

Cada registro define una hora, minuto y días de la semana para ejecutar una acción (ej\+: encender ventilador). Los registros se almacenan en NVS con claves "{}reg01"{} hasta "{}reg10"{} y persisten tras reinicios.

{\bfseries{Endpoints HTTP\+:}}
\begin{DoxyItemize}
\item POST /api/register -\/ Crear/actualizar registro
\item GET /api/register -\/ Listar todos los registros
\item DELETE /api/register?id=X -\/ Eliminar registro
\end{DoxyItemize}
